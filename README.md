(English description below)

Kirppis-varausjärjestelmä on Torppis Ry:lle toteutettu WordPress-lisäosa, jolla kirpputorin järjestäjät voivat hallita paikanvarauksia verkossa. Asiakkaat tekevät varaukset itse verkkosivuston lomakkeen kautta, ja järjestelmä lähettää heille automaattisen vahvistussähköpostin varauksen tiedoilla. Tarvittaessa vahvistussähköpostin mukana voidaan myös lähettää PDF laskuja.

Ominaisuudet:

- Paikanvarauslomake
- Reaaliajassa päivittyvä SVG kartta, joka näyttää vapaat ja varatut paikat
- Hallintapaneeli kirpputorin varausten hallintaan
- Automaattinen vahvistussähköpostien lähetys
- Mahdollisuus lähettää laskuja
- Varauslistan tulostus

In English:
Flea Market Reservation System is a WordPress plugin developed for Torppis Ry that enables flea market organizers to manage table reservations online. Customers can make reservations through a form on the website, after which the system automatically sends a confirmation email containing the reservation details. When needed, PDF invoices can also be attached to the confirmation email.

Features:

- Online table reservation form
- Real-time SVG map displaying available and reserved tables
- Administration panel for managing reservations
- Automatic confirmation email delivery
- PDF invoice support
- Printable reservation list
